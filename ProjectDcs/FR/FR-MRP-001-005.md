# FR-MRP-001-005 - Lot Sizing

**Business Requirement**: BR-MRP-001
**Functional Requirement ID**: FR-MRP-001-005
**Status**: Proposed
**Module**: ksf_FA_MRP
**PHP Version**: 7.3+

---

## 1. Requirement

The MRP system shall apply lot sizing rules to convert net requirements into planned order quantities.

## 2. Description

Lot sizing determines how much to order or produce when a requirement exists. Different methods balance ordering costs, holding costs, and production efficiency.

## 3. Acceptance Criteria

### 3.1 Lot-for-Lot (LFL)

| ID | Criterion | Test Method |
|----|-----------|-------------|
| AC-005-01 | Order quantity equals net requirement | Unit test |
| AC-005-02 | Each period's requirement ordered separately | Unit test |
| AC-005-03 | No lot size constraints applied | Unit test |

### 3.2 Economic Order Quantity (EOQ)

| ID | Criterion | Test Method |
|----|-----------|-------------|
| AC-005-04 | EOQ = sqrt((2 × D × S) / H) formula applied | Unit test |
| AC-005-05 | Annual demand (D) calculated from net requirements | Unit test |
| AC-005-06 | Ordering cost (S) read from item or default | Unit test |
| AC-005-07 | Holding cost rate (H) read from item or default | Unit test |
| AC-005-08 | EOQ used for first order, remainder carried forward | Unit test |

### 3.3 Fixed Order Quantity (FOQ)

| ID | Criterion | Test Method |
|----|-----------|-------------|
| AC-005-09 | Fixed lot size from item's reorder_quantity | Unit test |
| AC-005-10 | Multiple FOQ orders created if requirement exceeds FOQ | Unit test |
| AC-005-11 | Remainder less than FOQ creates single order | Unit test |

### 3.4 Period Order Quantity (POQ)

| ID | Criterion | Test Method |
|----|-----------|-------------|
| AC-005-12 | Requirements aggregated over fixed period | Unit test |

## 4. Lot Sizing Methods

### 4.1 Lot-for-Lot (LFL)

```
Requirement: 100, 50, 75, 80
Order Qty:   100, 50, 75, 80
Total:       305

Pros: No excess inventory, matches actual demand
Cons: High ordering costs
```

### 4.2 Economic Order Quantity (EOQ)

```
Annual Demand (D) = 10,000 units
Ordering Cost (S) = $50/order
Holding Cost (H) = $2/unit/year

EOQ = sqrt((2 × 10,000 × 50) / 2) = sqrt(500,000) = 707 units

Requirements: 100, 50, 75, 80
Orders: 707 (covers first 3 requirements), 707 (covers remaining + buffer)
```

### 4.3 Fixed Order Quantity (FOQ)

```
FOQ = 100
Requirements: 100, 50, 75, 80

Orders:
  - 100 (first requirement)
  - 100 (covers 50 + 50 of next)
  - 80 (last requirement)
```

### 4.4 Period Order Quantity (POQ)

```
Period = 2 weeks
Week 1 Req: 100, 50
Week 2 Req: 75, 80

POQ Order 1: 100 + 50 = 150
POQ Order 2: 75 + 80 = 155
```

## 5. Technical Implementation

### 5.1 Lot Sizing Service

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

/**
 * Lot Sizing Service.
 * Applies lot sizing rules to net requirements.
 *
 * @BABOK Related: FR-MRP-001-005
 */
class LotSizingService
{
    private $db;
    private $stockService;
    private $parameters;

    const LFL = 'LFL';
    const EOQ = 'EOQ';
    const FOQ = 'FOQ';
    const POQ = 'POQ';

    public function __construct(
        DbConnectionInterface $db,
        StockService $stockService,
        MRPParametersService $parameters
    ) {
        $this->db = $db;
        $this->stockService = $stockService;
        $this->parameters = $parameters;
    }

    /**
     * Apply lot sizing to net requirements.
     *
     * @param array $netRequirements Array of net requirements
     * @param string|null $method Override method, null uses parameter default
     * @return array Requirements with order quantities
     */
    public function applyLotSizing(array $netRequirements, $method = null): array
    {
        $method = $method ?? $this->parameters->getLotSizingMethod();

        switch ($method) {
            case self::EOQ:
                return $this->applyEOQ($netRequirements);
            case self::FOQ:
                return $this->applyFOQ($netRequirements);
            case self::POQ:
                return $this->applyPOQ($netRequirements);
            case self::LFL:
            default:
                return $this->applyLFL($netRequirements);
        }
    }

    /**
     * Lot-for-Lot: Order exactly what is needed.
     */
    private function applyLFL(array $netRequirements): array
    {
        foreach ($netRequirements as &$req) {
            $req['order_qty'] = $req['net_qty'];
            $req['lot_sizing_method'] = self::LFL;
        }

        return $netRequirements;
    }

    /**
     * Economic Order Quantity.
     */
    private function applyEOQ(array $netRequirements): array
    {
        $groupedByItem = $this->groupByItem($netRequirements);
        $results = [];

        foreach ($groupedByItem as $itemCode => $requirements) {
            $annualDemand = $this->calculateAnnualDemand($requirements);
            $orderingCost = $this->getOrderingCost($itemCode);
            $holdingCostRate = $this->getHoldingCostRate($itemCode);
            $unitCost = $this->getUnitCost($itemCode);

            $holdingCost = $unitCost * $holdingCostRate;

            if ($holdingCost > 0 && $annualDemand > 0) {
                $eoq = sqrt((2 * $annualDemand * $orderingCost) / $holdingCost);
                $eoq = $this->roundToUOM($itemCode, $eoq);
            } else {
                $eoq = array_sum(array_column($requirements, 'net_qty'));
            }

            $results = array_merge(
                $results,
                $this->distributeEOQ($requirements, $eoq)
            );
        }

        return $results;
    }

    /**
     * Fixed Order Quantity.
     */
    private function applyFOQ(array $netRequirements): array
    {
        $results = [];

        foreach ($netRequirements as $req) {
            $itemCode = $req['item_code'];
            $foq = $this->stockService->getReorderQuantity($itemCode);

            if ($foq <= 0) {
                $req['order_qty'] = $req['net_qty'];
                $req['lot_sizing_method'] = self::LFL;
                $results[] = $req;
                continue;
            }

            $remaining = $req['net_qty'];
            while ($remaining > 0) {
                $orderQty = min($foq, $remaining);

                $newReq = $req;
                $newReq['order_qty'] = $orderQty;
                $newReq['lot_sizing_method'] = self::FOQ;
                $results[] = $newReq;

                $remaining -= $orderQty;
            }
        }

        return $results;
    }

    /**
     * Period Order Quantity.
     */
    private function applyPOQ(array $netRequirements): array
    {
        $periodWeeks = (int)$this->parameters->get('poq_period_weeks') ?: 2;
        $results = [];

        $groupedByItem = $this->groupByItem($netRequirements);

        foreach ($groupedByItem as $itemCode => $requirements) {
            usort($requirements, function ($a, $b) {
                return strcmp($a['due_date'], $b['due_date']);
            });

            $periods = [];
            foreach ($requirements as $req) {
                $weekNum = (int)date('W', strtotime($req['due_date']));
                $year = (int)date('Y', strtotime($req['due_date']));
                $periodKey = floor($weekNum / $periodWeeks) * $periodWeeks;
                $periodGroup = $year . '-W' . str_pad((string)$periodKey, 2, '0', STR_PAD_LEFT);

                if (!isset($periods[$periodGroup])) {
                    $periods[$periodGroup] = [
                        'due_date' => $req['due_date'],
                        'net_qty' => 0
                    ];
                }

                $periods[$periodGroup]['net_qty'] += $req['net_qty'];
            }

            foreach ($periods as $periodGroup => $periodData) {
                $results[] = [
                    'item_code' => $itemCode,
                    'gross_qty' => $periodData['net_qty'],
                    'net_qty' => $periodData['net_qty'],
                    'order_qty' => $periodData['net_qty'],
                    'due_date' => $periodData['due_date'],
                    'lot_sizing_method' => self::POQ
                ];
            }
        }

        return $results;
    }

    private function groupByItem(array $requirements): array
    {
        $grouped = [];
        foreach ($requirements as $req) {
            $grouped[$req['item_code']][] = $req;
        }
        return $grouped;
    }

    private function calculateAnnualDemand(array $requirements): float
    {
        $totalNet = array_sum(array_column($requirements, 'net_qty'));
        $weeksInData = $this->getWeeksSpan($requirements);
        return $weeksInData > 0 ? ($totalNet / $weeksInData) * 52 : $totalNet * 52;
    }

    private function getWeeksSpan(array $requirements): float
    {
        if (count($requirements) < 2) {
            return 1;
        }

        $dates = array_column($requirements, 'due_date');
        $minDate = min($dates);
        $maxDate = max($dates);

        $days = (strtotime($maxDate) - strtotime($minDate)) / 86400;
        return max(1, $days / 7);
    }

    private function getOrderingCost(string $itemCode): float
    {
        $sql = "SELECT ordering_cost FROM 0_stock_master WHERE stock_id = " . $this->db->quote($itemCode);
        $cost = $this->db->fetchScalar($sql);
        return $cost !== null ? (float)$cost : 25.00;
    }

    private function getHoldingCostRate(string $itemCode): float
    {
        $sql = "SELECT holding_cost_rate FROM 0_stock_master WHERE stock_id = " . $this->db->quote($itemCode);
        $rate = $this->db->fetchScalar($sql);
        return $rate !== null ? (float)$rate : 0.20;
    }

    private function getUnitCost(string $itemCode): float
    {
        $sql = "SELECT material_cost + labour_cost + overhead_cost FROM 0_stock_master WHERE stock_id = " . $this->db->quote($itemCode);
        return (float)$this->db->fetchScalar($sql);
    }

    private function roundToUOM(string $itemCode, float $qty): float
    {
        $sql = "SELECT decimals FROM 0_stock_master WHERE stock_id = " . $this->db->quote($itemCode);
        $decimals = (int)$this->db->fetchScalar($sql);
        $multiplier = pow(10, $decimals);
        return ceil($qty * $multiplier) / $multiplier;
    }

    private function distributeEOQ(array $requirements, float $eoq): array
    {
        $results = [];
        $remainingRequirements = $requirements;

        while (!empty($remainingRequirements)) {
            $toCover = 0;
            $coveredRequirements = [];

            foreach ($remainingRequirements as $key => $req) {
                if ($toCover + $req['net_qty'] <= $eoq) {
                    $toCover += $req['net_qty'];
                    $coveredRequirements[] = $key;
                }
            }

            $results[] = [
                'item_code' => $remainingRequirements[0]['item_code'],
                'gross_qty' => $toCover,
                'net_qty' => $toCover,
                'order_qty' => $eoq,
                'due_date' => end($coveredRequirements) !== false
                    ? $remainingRequirements[end($coveredRequirements)]['due_date']
                    : $remainingRequirements[0]['due_date'],
                'lot_sizing_method' => self::EOQ
            ];

            $remainingRequirements = array_diff_key($remainingRequirements, array_flip($coveredRequirements));
            $remainingRequirements = array_values($remainingRequirements);
        }

        return $results;
    }
}
```
