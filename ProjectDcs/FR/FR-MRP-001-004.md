# FR-MRP-001-004 - Net Requirements Calculation

**Business Requirement**: BR-MRP-001
**Functional Requirement ID**: FR-MRP-001-004
**Status**: Proposed
**Module**: ksf_FA_MRP
**PHP Version**: 7.3+

---

## 1. Requirement

The MRP system shall calculate net requirements by subtracting available inventory and scheduled receipts from gross requirements.

## 2. Description

Net requirements calculation determines what must actually be ordered or produced by accounting for on-hand inventory, items on order from suppliers, and scheduled receipts from production.

## 4. Net Requirements Formula

### 4.1 Basic Formula

```
Net Requirement = Gross Requirement - Projected Available

Projected Available (before period) = On-Hand + On-Order + Scheduled Receipts - Safety Stock

If Projected Available >= 0: Net Requirement = 0
If Projected Available < 0: Net Requirement = |Projected Available|
```

### 4.2 Time-Phased Example

| Week | Gross | OnHand | OnOrder | Safety | Projected | Net |
|------|-------|--------|---------|--------|-----------|-----|
| 1    | 100   | 50     | 30      | 10     | -30       | 30  |
| 2    | 80    | 0      | 20      | 10     | -70       | 70  |
| 3    | 60    | 0      | 0       | 10     | -140      | 140 |

## 5. Technical Implementation

### 5.1 Net Requirements Calculator

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

/**
 * Net Requirements Calculator.
 * Calculates net requirements from gross requirements and inventory.
 *
 * @BABOK Related: FR-MRP-001-004
 */
class NetRequirementsCalculator
{
    private $db;
    private $stockService;
    private $purchasingService;

    public function __construct(
        DbConnectionInterface $db,
        StockService $stockService,
        PurchasingService $purchasingService
    ) {
        $this->db = $db;
        $this->stockService = $stockService;
        $this->purchasingService = $purchasingService;
    }

    /**
     * Calculate net requirements for exploded BOM requirements.
     *
     * @param array $explodedRequirements Array from BOM explosion
     * @return array Net requirements
     */
    public function calculate(array $explodedRequirements): array
    {
        $netRequirements = [];
        $runningAvailability = [];

        foreach ($explodedRequirements as $req) {
            $itemCode = $req['item_code'];
            $grossQty = $req['gross_qty'];
            $dueDate = $req['due_date'];

            if (!isset($runningAvailability[$itemCode])) {
                $runningAvailability[$itemCode] = $this->getInitialAvailability($itemCode);
            }

            $onHand = $this->stockService->getOnHand($itemCode);
            $onOrder = $this->purchasingService->getOnOrder($itemCode);
            $safetyStock = $this->stockService->getSafetyStock($itemCode);

            $projectedAvailable = $runningAvailability[$itemCode] + $onOrder - $safetyStock;

            $netQty = $grossQty - $projectedAvailable;
            $netQty = max(0, $netQty);

            $runningAvailability[$itemCode] = $projectedAvailable - $grossQty;

            if ($runningAvailability[$itemCode] < 0) {
                $runningAvailability[$itemCode] = 0;
            }

            $netRequirements[] = [
                'item_code' => $itemCode,
                'gross_qty' => $grossQty,
                'on_hand' => $onHand,
                'on_order' => $onOrder,
                'safety_stock' => $safetyStock,
                'projected_available' => $projectedAvailable,
                'net_qty' => $netQty,
                'due_date' => $dueDate,
                'shortage' => $netQty > 0
            ];
        }

        return $netRequirements;
    }

    /**
     * Get initial on-hand minus safety stock.
     */
    private function getInitialAvailability(string $itemCode): float
    {
        $onHand = $this->stockService->getOnHand($itemCode);
        $safetyStock = $this->stockService->getSafetyStock($itemCode);
        return $onHand - $safetyStock;
    }

    /**
     * Calculate requirements by time bucket.
     */
    public function calculateTimePhased(array $netRequirements, string $bucket = 'WEEK'): array
    {
        $bucketed = [];

        foreach ($netRequirements as $req) {
            $bucketKey = $this->getBucketKey($req['due_date'], $bucket);

            if (!isset($bucketed[$bucketKey])) {
                $bucketed[$bucketKey] = [
                    'bucket' => $bucketKey,
                    'items' => []
                ];
            }

            $itemCode = $req['item_code'];
            if (!isset($bucketed[$bucketKey]['items'][$itemCode])) {
                $bucketed[$bucketKey]['items'][$itemCode] = $req;
            } else {
                $bucketed[$bucketKey]['items'][$itemCode]['gross_qty'] += $req['gross_qty'];
                $bucketed[$bucketKey]['items'][$itemCode]['net_qty'] += $req['net_qty'];
            }
        }

        return array_values($bucketed);
    }

    private function getBucketKey(string $date, string $bucket): string
    {
        $timestamp = strtotime($date);

        if ($bucket === 'WEEK') {
            return date('Y-W', $timestamp);
        }

        return date('Y-m-d', $timestamp);
    }
}
```

```php
<?php
declare(strict_types=1);
```

### 5.3 Purchasing Service

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

class PurchasingService
{
    private $db;

    public function __construct(DbConnectionInterface $db)
    {
        $this->db = $db;
    }

    /**
     * Get total on-order quantity for item.
     * Includes open purchase orders.
     */
    public function getOnOrder(string $itemCode): float
    {
        $sql = "SELECT SUM(quantity_ordered - quantity_received) AS on_order
                FROM 0_purch_order_details pod
                JOIN 0_purch_orders po ON pod.order_no = po.order_no
                WHERE pod.item_code = " . $this->db->quote($itemCode) . "
                  AND po.ord_status = 1
                  AND pod.quantity_ordered > pod.quantity_received";

        return (float)$this->db->fetchScalar($sql);
    }

    /**
     * Get scheduled receipts for item within date range.
     */
    public function getScheduledReceipts(string $itemCode, string $fromDate, string $toDate): array
    {
        $sql = "SELECT pod.*, po.ord_date, po.supplier_id, po.supplier_name
                FROM 0_purch_order_details pod
                JOIN 0_purch_orders po ON pod.order_no = po.order_no
                WHERE pod.item_code = " . $this->db->quote($itemCode) . "
                  AND po.ord_status = 1
                  AND pod.delivery_date BETWEEN " . $this->db->quote($fromDate) . "
                  AND " . $this->db->quote($toDate) . "
                  AND pod.quantity_ordered > pod.quantity_received";

        return $this->db->fetchAll($sql);
    }

    /**
     * Get open work orders for item.
     */
    public function getOpenWorkOrders(string $itemCode): array
    {
        $sql = "SELECT wo.*, woi.loc_code
                FROM 0_workorders wo
                LEFT JOIN 0_wo_issues woi ON wo.id = woi.issue_no
                WHERE wo.stock_id = " . $this->db->quote($itemCode) . "
                  AND wo.status IN (1, 2)";

        return $this->db->fetchAll($sql);
    }
}
```
