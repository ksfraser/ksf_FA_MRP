# FR-MRP-001-003 - BOM Explosion

**Business Requirement**: BR-MRP-001
**Functional Requirement ID**: FR-MRP-001-003
**Status**: Proposed
**Module**: ksf_FA_MRP
**PHP Version**: 7.3+

---

## 1. Requirement

The MRP system shall explode the Bill of Materials (BOM) to convert parent item demands into component requirements across all BOM levels.

## 2. Description

BOM explosion takes aggregated demands for parent items and recursively expands them through the BOM structure to determine gross requirements for all component items at every level.

## 4. Explosion Algorithm

### 4.1 Single-Level Explosion

```
Parent Item A requires:
  - 2 units of Component B
  - 3 units of Component C

If 5 units of A are demanded:
  - Gross requirement for B = 5 × 2 = 10
  - Gross requirement for C = 5 × 3 = 15
```

### 4.2 Multi-Level Explosion

```
Level 0: Product A (1)
Level 1: ├── Component B (2)
Level 1: └── Component C (1)
Level 2:     └── Component D (3)

Demand: 5 units of A

Explosion:
  - A × 5 → B × 10, C × 5
  - C × 5 → D × 15

Total requirements:
  - B: 10
  - C: 5
  - D: 15
```

## 5. Technical Implementation

### 5.1 BOM Exploder Class

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

/**
 * BOM Exploder Service.
 * Performs multi-level Bill of Materials explosion.
 *
 * @BABOK Related: FR-MRP-001-003
 */
class BOMExploder
{
    private $db;
    private $bomDAO;
    private $parameters;
    private $maxDepth = 20;

    public function __construct(DbConnectionInterface $db, BOMDAO $bomDAO, MRPParametersService $parameters)
    {
        $this->db = $db;
        $this->bomDAO = $bomDAO;
        $this->parameters = $parameters;
    }

    /**
     * Explode demands through BOM.
     *
     * @param array $demands Array of demand records with item_code, quantity, due_date
     * @return array Exploded requirements
     */
    public function explode(array $demands): array
    {
        $requirements = [];
        $processed = [];

        foreach ($demands as $demand) {
            $this->explodeItem(
                $demand['item_code'],
                $demand['quantity'],
                $demand['due_date'],
                1,
                $requirements,
                $processed
            );
        }

        return $this->aggregateRequirements($requirements);
    }

    /**
     * Recursively explode a single item through its BOM.
     */
    private function explodeItem(
        string $itemCode,
        float $quantity,
        string $dueDate,
        int $level,
        array &$requirements,
        array &$processed
    ): void {
        if ($level > $this->maxDepth) {
            return;
        }

        if (isset($processed[$itemCode])) {
            return;
        }

        $bomItems = $this->bomDAO->getBOMItems($itemCode);

        foreach ($bomItems as $bomItem) {
            $componentCode = $bomItem['component'];
            $componentQty = $bomItem['quantity'] * $quantity;

            if ($this->isPhantom($componentCode)) {
                $this->explodeItem(
                    $componentCode,
                    $componentQty,
                    $dueDate,
                    $level + 1,
                    $requirements,
                    $processed
                );
                continue;
            }

            $requirements[] = [
                'item_code' => $componentCode,
                'gross_qty' => $componentQty,
                'due_date' => $dueDate,
                'level' => $level,
                'parent_item' => $itemCode
            ];
        }

        $processed[$itemCode] = true;
    }

    /**
     * Check if item is a phantom (transient) item.
     */
    private function isPhantom(string $itemCode): bool
    {
        if (!$this->parameters->get('phantom_dissolve')) {
            return false;
        }

        return $this->bomDAO->isPhantomItem($itemCode);
    }

    /**
     * Aggregate requirements by item code and due date.
     */
    private function aggregateRequirements(array $requirements): array
    {
        $aggregated = [];

        foreach ($requirements as $req) {
            $key = $req['item_code'] . '|' . $req['due_date'];

            if (!isset($aggregated[$key])) {
                $aggregated[$key] = $req;
            } else {
                $aggregated[$key]['gross_qty'] += $req['gross_qty'];
            }
        }

        return array_values($aggregated);
    }
}
```

### 5.2 BOM Data Access

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

class BOMDAO
{
    private $db;

    public function __construct(DbConnectionInterface $db)
    {
        $this->db = $db;
    }

    /**
     * Get BOM items for a parent.
     *
     * @param string $parentCode Parent item code
     * @return array BOM items
     */
    public function getBOMItems(string $parentCode): array
    {
        $sql = "SELECT bom.parent, bom.component, bom.quantity,
                       sm.units, sm.item_description, sm.is_phantom
                FROM 0_bom bom
                JOIN 0_stock_master sm ON bom.component = sm.stock_id
                WHERE bom.parent = " . $this->db->quote($parentCode) . "
                  AND bom.enabled = 1
                ORDER BY bom.component";

        return $this->db->fetchAll($sql);
    }

    /**
     * Check if item is a phantom.
     *
     * @param string $itemCode Item code
     * @return bool True if phantom
     */
    public function isPhantomItem(string $itemCode): bool
    {
        $sql = "SELECT is_phantom FROM 0_stock_master 
                WHERE stock_id = " . $this->db->quote($itemCode);

        $result = $this->db->fetchScalar($sql);
        return $result == 1;
    }

    /**
     * Get item lead time.
     *
     * @param string $itemCode Item code
     * @return int Lead time in days
     */
    public function getLeadTime(string $itemCode): int
    {
        $sql = "SELECT lead_time FROM 0_stock_master 
                WHERE stock_id = " . $this->db->quote($itemCode);

        return (int)$this->db->fetchScalar($sql);
    }

    /**
     * Check for circular BOM reference.
     *
     * @param string $itemCode Item to check
     * @param string $topLevel Top-level parent
     * @return bool True if circular
     */
    public function hasCircularReference(string $itemCode, string $topLevel): bool
    {
        $visited = [];
        return $this->checkCircular($itemCode, $topLevel, $visited);
    }

    private function checkCircular(string $current, string $topLevel, array &$visited): bool
    {
        if ($current === $topLevel) {
            return true;
        }

        if (isset($visited[$current])) {
            return false;
        }

        $visited[$current] = true;
        $bomItems = $this->getBOMItems($current);

        foreach ($bomItems as $item) {
            if ($this->checkCircular($item['component'], $topLevel, $visited)) {
                return true;
            }
        }

        return false;
    }
}
```

## 6. Unit Test

```php
<?php
declare(strict_types=1);

namespace Tests\Unit;

use PHPUnit\Framework\TestCase;

class BOMExploderTest extends TestCase
{
    private $db;
    private $bomDAO;
    private $parameters;
    private $exploder;

    protected function setUp(): void
    {
        $this->db = $this->createMock(DbConnectionInterface::class);
        $this->bomDAO = $this->createMock(BOMDAO::class);
        $this->parameters = $this->createMock(MRPParametersService::class);

        $this->exploder = new BOMExploder($this->db, $this->bomDAO, $this->parameters);
    }

    /**
     * @BABOK Related: UT-MRP-001-001-001
     */
    public function testSingleLevelExplosion(): void
    {
        $this->bomDAO->method('getBOMItems')
            ->with('PRODUCT-A')
            ->willReturn([
                ['component' => 'COMP-B', 'quantity' => 2],
                ['component' => 'COMP-C', 'quantity' => 3]
            ]);

        $this->bomDAO->method('isPhantomItem')
            ->willReturn(false);

        $demands = [
            ['item_code' => 'PRODUCT-A', 'quantity' => 5, 'due_date' => '2024-01-15']
        ];

        $result = $this->exploder->explode($demands);

        $this->assertCount(2, $result);

        $compB = array_filter($result, fn($r) => $r['item_code'] === 'COMP-B');
        $compC = array_filter($result, fn($r) => $r['item_code'] === 'COMP-C');

        $this->assertEquals(10, reset($compB)['gross_qty']);
        $this->assertEquals(15, reset($compC)['gross_qty']);
    }

    /**
     * @BABOK Related: UT-MRP-001-001-001
     */
    public function testMultiLevelExplosion(): void
    {
        $this->bomDAO->method('getBOMItems')
            ->willReturnCallback(function ($code) {
                if ($code === 'PRODUCT-A') {
                    return [
                        ['component' => 'SUB-ASSY-B', 'quantity' => 2]
                    ];
                }
                if ($code === 'SUB-ASSY-B') {
                    return [
                        ['component' => 'COMP-C', 'quantity' => 3]
                    ];
                }
                return [];
            });

        $this->bomDAO->method('isPhantomItem')
            ->willReturn(false);

        $demands = [
            ['item_code' => 'PRODUCT-A', 'quantity' => 5, 'due_date' => '2024-01-15']
        ];

        $result = $this->exploder->explode($demands);

        $this->assertCount(1, $result);
        $this->assertEquals('COMP-C', $result[0]['item_code']);
        $this->assertEquals(30, $result[0]['gross_qty']);
        $this->assertEquals(2, $result[0]['level']);
    }

    /**
     * @BABOK Related: UT-MRP-001-001-001
     */
    public function testPhantomDissolve(): void
    {
        $this->bomDAO->method('getBOMItems')
            ->willReturnCallback(function ($code) {
                if ($code === 'PRODUCT-A') {
                    return [
                        ['component' => 'PHANTOM-P', 'quantity' => 2]
                    ];
                }
                if ($code === 'PHANTOM-P') {
                    return [
                        ['component' => 'COMP-C', 'quantity' => 4]
                    ];
                }
                return [];
            });

        $this->bomDAO->method('isPhantomItem')
            ->willReturn(false);

        $this->parameters->method('get')
            ->with('phantom_dissolve')
            ->willReturn(1);

        $this->bomDAO->method('isPhantomItem')
            ->with('PHANTOM-P')
            ->willReturn(true);

        $demands = [
            ['item_code' => 'PRODUCT-A', 'quantity' => 5, 'due_date' => '2024-01-15']
        ];

        $result = $this->exploder->explode($demands);

        $this->assertCount(1, $result);
        $this->assertEquals('COMP-C', $result[0]['item_code']);
        $this->assertEquals(40, $result[0]['gross_qty']);
    }

    public function testPhantomPreserved(): void
    {
        $this->bomDAO->method('getBOMItems')
            ->willReturnCallback(function ($code) {
                if ($code === 'PRODUCT-A') {
                    return [
                        ['component' => 'PHANTOM-P', 'quantity' => 2]
                    ];
                }
                if ($code === 'PHANTOM-P') {
                    return [
                        ['component' => 'COMP-C', 'quantity' => 4]
                    ];
                }
                return [];
            });

        $this->bomDAO->method('isPhantomItem')
            ->with('PHANTOM-P')
            ->willReturn(true);

        $this->parameters->method('get')
            ->with('phantom_dissolve')
            ->willReturn(0);

        $demands = [
            ['item_code' => 'PRODUCT-A', 'quantity' => 5, 'due_date' => '2024-01-15']
        ];

        $result = $this->exploder->explode($demands);

        $this->assertCount(1, $result);
        $this->assertEquals('PHANTOM-P', $result[0]['item_code']);
        $this->assertEquals(10, $result[0]['gross_qty']);
    }

    public function testDemandAggregation(): void
    {
        $this->bomDAO->method('getBOMItems')
            ->with('PRODUCT-A')
            ->willReturn([
                ['component' => 'COMP-B', 'quantity' => 1]
            ]);

        $this->bomDAO->method('isPhantomItem')
            ->willReturn(false);

        $demands = [
            ['item_code' => 'PRODUCT-A', 'quantity' => 5, 'due_date' => '2024-01-15'],
            ['item_code' => 'PRODUCT-A', 'quantity' => 3, 'due_date' => '2024-01-15']
        ];

        $result = $this->exploder->explode($demands);

        $this->assertCount(1, $result);
        $this->assertEquals(8, $result[0]['gross_qty']);
    }

    public function testMaxDepthEnforced(): void
    {
        $bomItems = [];
        for ($i = 1; $i <= 25; $i++) {
            $bomItems['ITEM-' . $i] = [
                ['component' => 'ITEM-' . ($i + 1), 'quantity' => 1]
            ];
        }
        $bomItems['ITEM-25'] = [];

        $this->bomDAO->method('getBOMItems')
            ->willReturnCallback(function ($code) use ($bomItems) {
                return $bomItems[$code] ?? [];
            });

        $this->bomDAO->method('isPhantomItem')
            ->willReturn(false);

        $demands = [
            ['item_code' => 'ITEM-1', 'quantity' => 1, 'due_date' => '2024-01-15']
        ];

        $result = $this->exploder->explode($demands);

        $this->assertCount(1, $result);
        $this->assertEquals('ITEM-21', $result[0]['item_code']);
    }
}
```
