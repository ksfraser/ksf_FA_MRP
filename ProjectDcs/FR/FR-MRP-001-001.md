# FR-MRP-001-001 - MRP Parameters

**Business Requirement**: BR-MRP-001
**Functional Requirement ID**: FR-MRP-001-001
**Status**: Proposed
**Module**: ksf_FA_MRP
**PHP Version**: 7.3+

---

## 1. Requirement

The MRP system shall maintain configuration parameters that control MRP planning behavior.

## 2. Description

MRP parameters define the planning horizon, time bucket size, lot sizing defaults, and other planning options that affect how MRP calculations are performed.

## 3. Acceptance Criteria

## 4. Parameter Definitions

### 4.1 planning_horizon_days

| Property | Value |
|----------|-------|
| Type | INTEGER |
| Default | 30 |
| Min | 1 |
| Max | 365 |
| Description | Number of days ahead to plan requirements |

### 4.2 time_bucket

| Property | Value |
|----------|-------|
| Type | ENUM |
| Default | WEEK |
| Options | DAY, WEEK |
| Description | Time bucket for grouping requirements |

### 4.3 lot_sizing_method

| Property | Value |
|----------|-------|
| Type | ENUM |
| Default | LFL |
| Options | LFL, EOQ, FOQ, POQ |
| Description | Default lot sizing method |

### 4.4 safety_stock_method

| Property | Value |
|----------|-------|
| Type | ENUM |
| Default | NONE |
| Options | NONE, PERCENTAGE, FIXED |
| Description | Safety stock calculation method |

### 4.5 phantom_dissolve

| Property | Value |
|----------|-------|
| Type | BOOLEAN |
| Default | 1 (true) |
| Description | Whether to dissolve phantom items in BOM explosion |

### 4.6 low_level_code

| Property | Value |
|----------|-------|
| Type | BOOLEAN |
| Default | 1 (true) |
| Description | Whether to use low-level coding for BOM explosion |

## 5. Technical Implementation

### 5.1 Database Access Class

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

/**
 * MRP Parameters Data Access.
 *
 * @BABOK Related: FR-MRP-001-001
 */
class MRPParametersDAO
{
    private $db;

    public function __construct(DbConnectionInterface $db)
    {
        $this->db = $db;
    }

    public function get(string $parameterId)
    {
        $sql = "SELECT parameter_value FROM 0_mrp_parameters 
                WHERE parameter_id = " . $this->db->quote($parameterId);
        return $this->db->fetchScalar($sql);
    }

    public function set(string $parameterId, $value): bool
    {
        $sql = "INSERT INTO 0_mrp_parameters (parameter_id, parameter_value)
                VALUES (" . $this->db->quote($parameterId) . ", " . $this->db->quote($value) . ")
                ON DUPLICATE KEY UPDATE parameter_value = " . $this->db->quote($value);
        return $this->db->executeUpdate($sql) !== false;
    }

    public function getAll(): array
    {
        $sql = "SELECT * FROM 0_mrp_parameters";
        return $this->db->fetchAll($sql);
    }

    public function initializeDefaults(): void
    {
        $defaults = [
            'planning_horizon_days' => 30,
            'time_bucket' => 'WEEK',
            'lot_sizing_method' => 'LFL',
            'safety_stock_method' => 'NONE',
            'phantom_dissolve' => 1,
            'low_level_code' => 1
        ];

        foreach ($defaults as $key => $value) {
            $this->set($key, $value);
        }
    }
}
```

### 5.2 Service Layer

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

class MRPParametersService
{
    private $dao;

    public function __construct(MRPParametersDAO $dao)
    {
        $this->dao = $dao;
    }

    public function getPlanningHorizon(): int
    {
        return (int)$this->dao->get('planning_horizon_days');
    }

    public function setPlanningHorizon(int $days): bool
    {
        if ($days < 1 || $days > 365) {
            return false;
        }
        return $this->dao->set('planning_horizon_days', $days);
    }

    public function getTimeBucket(): string
    {
        return $this->dao->get('time_bucket');
    }

    public function getLotSizingMethod(): string
    {
        return $this->dao->get('lot_sizing_method');
    }
}
```
