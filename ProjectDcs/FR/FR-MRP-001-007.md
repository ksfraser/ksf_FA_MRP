# FR-MRP-001-007 - Action Messages

**Business Requirement**: BR-MRP-001
**Functional Requirement ID**: FR-MRP-001-007
**Status**: Proposed
**Module**: ksf_FA_MRP
**PHP Version**: 7.3+

---

## 1. Requirement

The MRP system shall generate action messages that recommend specific procurement or production actions to the planner.

## 2. Description

Action messages are the "alerts" that come from MRP processing, indicating what actions should be taken: place a new order, reschedule an existing order, or cancel an order.

## 4. Message Types

### 4.1 ORDER

```
Type: ORDER
Priority: 1 (High)
Trigger: New planned order with no matching existing order
Action: Create purchase order or work order
Example: "ORDER 100 units of COMP-A by 2024-01-15"
```

### 4.2 RESCHEDULE

```
Type: RESCHEDULE
Priority: 2 (Medium)
Trigger: Existing order date differs from planned date
Action: Change order date
Example: "RESCHEDULE PO-A from 2024-01-10 to 2024-01-12"
```

### 4.3 CANCEL

```
Type: CANCEL
Priority: 1 (High)
Trigger: Existing order not needed (requirement removed)
Action: Cancel the order
Example: "CANCEL PO-A for COMP-B - no longer required"
```

### 4.4 EXPEDITE

```
Type: EXPEDITE
Priority: 1 (High)
Trigger: Order needed sooner than planned
Action: Speed up existing order
Example: "EXPEDITE PO-A - needed by 2024-01-10 instead of 2024-01-15"
```

### 4.5 DEFER

```
Type: DEFER
Priority: 3 (Low)
Trigger: Order can be delayed
Action: Push out order date
Example: "DEFER PO-A - can wait until 2024-01-20"
```

## 5. Technical Implementation

### 5.1 Action Message Generator

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

/**
 * Action Message Generator.
 * Generates action messages from MRP results.
 *
 * @BABOK Related: FR-MRP-001-007
 */
class ActionMessageGenerator
{
    private $db;

    const ACTION_ORDER = 'ORDER';
    const ACTION_RESCHEDULE = 'RESCHEDULE';
    const ACTION_CANCEL = 'CANCEL';
    const ACTION_EXPEDITE = 'EXPEDITE';
    const ACTION_DEFER = 'DEFER';

    const PRIORITY_HIGH = 1;
    const PRIORITY_MEDIUM = 2;
    const PRIORITY_LOW = 3;

    public function __construct(DbConnectionInterface $db)
    {
        $this->db = $db;
    }

    /**
     * Generate action messages by comparing planned orders to existing.
     *
     * @param array $plannedOrders Planned orders from MRP
     * @param array $existingOrders Existing open orders (POs, WOs)
     * @return array Action messages
     */
    public function generate(array $plannedOrders, array $existingOrders = []): array
    {
        $messages = [];
        $existingByItem = $this->indexByItem($existingOrders);

        foreach ($plannedOrders as $planned) {
            $itemCode = $planned['item_code'];
            $existing = $existingByItem[$itemCode] ?? null;

            if ($existing === null) {
                $messages[] = $this->createOrderMessage($planned);
            } elseif ($this->needsReschedule($planned, $existing)) {
                if ($this->needsEarlierDate($planned, $existing)) {
                    $messages[] = $this->createExpediteMessage($planned, $existing);
                } else {
                    $messages[] = $this->createRescheduleMessage($planned, $existing);
                }
            } elseif ($this->needsQuantityChange($planned, $existing)) {
                $messages[] = $this->createRescheduleMessage($planned, $existing);
            }
        }

        foreach ($existingOrders as $existing) {
            if (!$this->hasPlannedOrder($existing, $plannedOrders)) {
                $messages[] = $this->createCancelMessage($existing);
            }
        }

        return $this->prioritizeMessages($messages);
    }

    /**
     * Index existing orders by item code.
     */
    private function indexByItem(array $orders): array
    {
        $indexed = [];
        foreach ($orders as $order) {
            $key = $order['item_code'];
            if (!isset($indexed[$key])) {
                $indexed[$key] = $order;
            }
        }
        return $indexed;
    }

    /**
     * Check if order needs rescheduling.
     */
    private function needsReschedule(array $planned, array $existing): bool
    {
        return $planned['due_date'] !== $existing['due_date'];
    }

    /**
     * Check if planned date is earlier than existing.
     */
    private function needsEarlierDate(array $planned, array $existing): bool
    {
        return strtotime($planned['due_date']) < strtotime($existing['due_date']);
    }

    /**
     * Check if quantity needs to change.
     */
    private function needsQuantityChange(array $planned, array $existing): bool
    {
        $plannedQty = (float)$planned['quantity'];
        $existingQty = (float)$existing['quantity'];
        $tolerance = 0.01;

        return abs($plannedQty - $existingQty) > $tolerance;
    }

    /**
     * Check if existing order has a planned order.
     */
    private function hasPlannedOrder(array $existing, array $plannedOrders): bool
    {
        foreach ($plannedOrders as $planned) {
            if ($planned['item_code'] === $existing['item_code']) {
                return true;
            }
        }
        return false;
    }

    /**
     * Create ORDER message.
     */
    private function createOrderMessage(array $planned): array
    {
        return [
            'item_code' => $planned['item_code'],
            'action_type' => self::ACTION_ORDER,
            'old_date' => null,
            'new_date' => $planned['due_date'],
            'old_quantity' => null,
            'new_quantity' => $planned['quantity'],
            'priority' => self::PRIORITY_HIGH,
            'message_text' => sprintf(
                "ORDER %s units of %s by %s",
                number_format($planned['quantity'], 2),
                $planned['item_code'],
                $planned['due_date']
            )
        ];
    }

    /**
     * Create RESCHEDULE message.
     */
    private function createRescheduleMessage(array $planned, array $existing): array
    {
        return [
            'item_code' => $planned['item_code'],
            'action_type' => self::ACTION_RESCHEDULE,
            'old_date' => $existing['due_date'],
            'new_date' => $planned['due_date'],
            'old_quantity' => $existing['quantity'],
            'new_quantity' => $planned['quantity'],
            'priority' => self::PRIORITY_MEDIUM,
            'message_text' => sprintf(
                "RESCHEDULE %s from %s to %s",
                $planned['item_code'],
                $existing['due_date'],
                $planned['due_date']
            )
        ];
    }

    /**
     * Create EXPEDITE message.
     */
    private function createExpediteMessage(array $planned, array $existing): array
    {
        return [
            'item_code' => $planned['item_code'],
            'action_type' => self::ACTION_EXPEDITE,
            'old_date' => $existing['due_date'],
            'new_date' => $planned['due_date'],
            'old_quantity' => $existing['quantity'],
            'new_quantity' => $planned['quantity'],
            'priority' => self::PRIORITY_HIGH,
            'message_text' => sprintf(
                "EXPEDITE %s - needed by %s instead of %s",
                $planned['item_code'],
                $planned['due_date'],
                $existing['due_date']
            )
        ];
    }

    /**
     * Create CANCEL message.
     */
    private function createCancelMessage(array $existing): array
    {
        return [
            'item_code' => $existing['item_code'],
            'action_type' => self::ACTION_CANCEL,
            'old_date' => $existing['due_date'],
            'new_date' => null,
            'old_quantity' => $existing['quantity'],
            'new_quantity' => null,
            'priority' => self::PRIORITY_HIGH,
            'message_text' => sprintf(
                "CANCEL order for %s - no longer required",
                $existing['item_code']
            )
        ];
    }

    /**
     * Create DEFER message.
     */
    private function createDeferMessage(array $planned, array $existing): array
    {
        return [
            'item_code' => $planned['item_code'],
            'action_type' => self::ACTION_DEFER,
            'old_date' => $existing['due_date'],
            'new_date' => $planned['due_date'],
            'old_quantity' => $existing['quantity'],
            'new_quantity' => $planned['quantity'],
            'priority' => self::PRIORITY_LOW,
            'message_text' => sprintf(
                "DEFER %s - can wait until %s",
                $planned['item_code'],
                $planned['due_date']
            )
        ];
    }

    /**
     * Sort messages by priority.
     */
    private function prioritizeMessages(array $messages): array
    {
        usort($messages, function ($a, $b) {
            return $a['priority'] <=> $b['priority'];
        });
        return $messages;
    }

    /**
     * Save messages to database.
     */
    public function save(array $messages): bool
    {
        $this->db->executeUpdate("DELETE FROM 0_mrp_action_messages WHERE acknowledged = 0");

        foreach ($messages as $msg) {
            $sql = "INSERT INTO 0_mrp_action_messages 
                    (item_code, action_type, old_date, new_date, 
                     old_quantity, new_quantity, priority)
                    VALUES (
                        " . $this->db->quote($msg['item_code']) . ",
                        " . $this->db->quote($msg['action_type']) . ",
                        " . ($msg['old_date'] ? $this->db->quote($msg['old_date']) : 'NULL') . ",
                        " . ($msg['new_date'] ? $this->db->quote($msg['new_date']) : 'NULL') . ",
                        " . ($msg['old_quantity'] !== null ? $msg['old_quantity'] : 'NULL') . ",
                        " . ($msg['new_quantity'] !== null ? $msg['new_quantity'] : 'NULL') . ",
                        " . $msg['priority'] . "
                    )";
            $this->db->executeUpdate($sql);
        }

        return true;
    }

    /**
     * Acknowledge a message.
     */
    public function acknowledge(int $messageId, int $userId): bool
    {
        $sql = "UPDATE 0_mrp_action_messages 
                SET acknowledged = 1, acknowledged_by = " . (int)$userId . ",
                    acknowledged_at = NOW()
                WHERE message_id = " . (int)$messageId;

        return $this->db->executeUpdate($sql) !== false;
    }

    /**
     * Get unacknowledged messages.
     */
    public function getMessages(bool $acknowledgedOnly = false): array
    {
        $sql = "SELECT * FROM 0_mrp_action_messages WHERE 1=1";

        if (!$acknowledgedOnly) {
            $sql .= " AND acknowledged = 0";
        }

        $sql .= " ORDER BY priority, created_at DESC";

        return $this->db->fetchAll($sql);
    }

    /**
     * Get message count by type.
     */
    public function getMessageCounts(): array
    {
        $sql = "SELECT action_type, COUNT(*) as count 
                FROM 0_mrp_action_messages 
                WHERE acknowledged = 0 
                GROUP BY action_type";

        return $this->db->fetchAll($sql);
    }
}
```

### 5.2 Database Schema

```sql
CREATE TABLE IF NOT EXISTS `0_mrp_action_messages` (
    `message_id` INT(11) NOT NULL AUTO_INCREMENT,
    `item_code` VARCHAR(20) NOT NULL,
    `action_type` VARCHAR(20) NOT NULL COMMENT 'ORDER, RESCHEDULE, CANCEL, EXPEDITE, DEFER',
    `old_date` DATE DEFAULT NULL,
    `new_date` DATE DEFAULT NULL,
    `old_quantity` DECIMAL(15,3) DEFAULT NULL,
    `new_quantity` DECIMAL(15,3) DEFAULT NULL,
    `priority` INT(11) DEFAULT 1,
    `acknowledged` TINYINT(1) DEFAULT 0,
    `acknowledged_by` INT(11) DEFAULT NULL,
    `acknowledged_at` TIMESTAMP NULL DEFAULT NULL,
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`message_id`),
    KEY `idx_item_code` (`item_code`),
    KEY `idx_action_type` (`action_type`),
    KEY `idx_acknowledged` (`acknowledged`),
    KEY `idx_priority` (`priority`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
