# FR-MRP-001-006 - Planned Order Generation

**Business Requirement**: BR-MRP-001
**Functional Requirement ID**: FR-MRP-001-006
**Status**: Proposed
**Module**: ksf_FA_MRP
**PHP Version**: 7.3+

---

## 1. Requirement

The MRP system shall generate planned orders (purchase requisitions and work orders) from net requirements after lot sizing.

## 2. Description

Planned orders are the output of MRP - suggestions for what to order or produce, including quantities and dates. These can be firmed into actual purchase orders or work orders.

## 5. Technical Implementation

### 5.1 Planned Order Generator

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

/**
 * Planned Order Generator.
 * Generates planned orders from lot-sized requirements.
 *
 * @BABOK Related: FR-MRP-001-006
 */
class PlannedOrderGenerator
{
    private $db;
    private $bomDAO;
    private $lotSizingService;

    const STATUS_PLANNED = 'PLANNED';
    const STATUS_FIRM = 'FIRM';
    const STATUS_CONVERTED = 'CONVERTED';

    const TYPE_PURCHASE = 'PO';
    const TYPE_WORK_ORDER = 'WO';

    public function __construct(
        DbConnectionInterface $db,
        BOMDAO $bomDAO,
        LotSizingService $lotSizingService
    ) {
        $this->db = $db;
        $this->bomDAO = $bomDAO;
        $this->lotSizingService = $lotSizingService;
    }

    /**
     * Generate planned orders from net requirements.
     *
     * @param array $netRequirements Net requirements after lot sizing
     * @return array Planned orders
     */
    public function generate(array $netRequirements): array
    {
        $plannedOrders = [];

        foreach ($netRequirements as $req) {
            if ($req['net_qty'] <= 0) {
                continue;
            }

            $orderType = $this->determineOrderType($req['item_code']);
            $leadTime = $this->bomDAO->getLeadTime($req['item_code']);
            $dueDate = $req['due_date'];
            $startDate = $this->calculateStartDate($dueDate, $leadTime);

            $plannedOrders[] = [
                'item_code' => $req['item_code'],
                'order_type' => $orderType,
                'quantity' => $req['order_qty'] ?? $req['net_qty'],
                'due_date' => $dueDate,
                'start_date' => $startDate,
                'source_demand_id' => $req['demand_id'] ?? null,
                'status' => self::STATUS_PLANNED,
                'firm' => 0,
                'lot_sizing_method' => $req['lot_sizing_method'] ?? 'LFL'
            ];
        }

        return $plannedOrders;
    }

    /**
     * Determine if item is purchased or manufactured.
     */
    private function determineOrderType(string $itemCode): string
    {
        $sql = "SELECT mb_flag FROM 0_stock_master WHERE stock_id = " . $this->db->quote($itemCode);
        $mbFlag = $this->db->fetchScalar($sql);

        return ($mbFlag === 'M' || $mbFlag === 'B') ? self::TYPE_WORK_ORDER : self::TYPE_PURCHASE;
    }

    /**
     * Calculate start date from due date and lead time.
     */
    private function calculateStartDate(string $dueDate, int $leadTime): string
    {
        $startTimestamp = strtotime($dueDate) - ($leadTime * 86400);
        return date('Y-m-d', $startTimestamp);
    }

    /**
     * Save planned orders to database.
     */
    public function save(array $plannedOrders): bool
    {
        $this->db->executeUpdate("DELETE FROM 0_mrp_planned_orders WHERE firm = 0");

        foreach ($plannedOrders as $order) {
            $sql = "INSERT INTO 0_mrp_planned_orders 
                    (item_code, order_type, quantity, due_date, start_date, 
                     source_demand_id, status, firm)
                    VALUES (
                        " . $this->db->quote($order['item_code']) . ",
                        " . $this->db->quote($order['order_type']) . ",
                        " . $order['quantity'] . ",
                        " . $this->db->quote($order['due_date']) . ",
                        " . $this->db->quote($order['start_date']) . ",
                        " . (isset($order['source_demand_id']) ? (int)$order['source_demand_id'] : 'NULL') . ",
                        " . $this->db->quote($order['status']) . ",
                        " . (int)$order['firm'] . "
                    )";
            $this->db->executeUpdate($sql);
        }

        return true;
    }

    /**
     * Firm a planned order.
     */
    public function firmOrder(int $orderId): bool
    {
        $sql = "UPDATE 0_mrp_planned_orders 
                SET firm = 1, status = " . $this->db->quote(self::STATUS_FIRM) . "
                WHERE order_id = " . (int)$orderId;

        return $this->db->executeUpdate($sql) !== false;
    }

    /**
     * Unfirm a planned order.
     */
    public function unfirmOrder(int $orderId): bool
    {
        $sql = "UPDATE 0_mrp_planned_orders 
                SET firm = 0, status = " . $this->db->quote(self::STATUS_PLANNED) . "
                WHERE order_id = " . (int)$orderId;

        return $this->db->executeUpdate($sql) !== false;
    }

    /**
     * Get planned orders for item.
     */
    public function getPlannedOrders(string $itemCode = null): array
    {
        $sql = "SELECT * FROM 0_mrp_planned_orders WHERE 1=1";

        if ($itemCode !== null) {
            $sql .= " AND item_code = " . $this->db->quote($itemCode);
        }

        $sql .= " ORDER BY due_date";

        return $this->db->fetchAll($sql);
    }

    /**
     * Convert planned order to purchase requisition.
     */
    public function convertToPurchaseRequisition(int $orderId): ?int
    {
        $order = $this->getOrderById($orderId);
        if (!$order || $order['order_type'] !== self::TYPE_PURCHASE) {
            return null;
        }

        $sql = "INSERT INTO 0_purch_requisitions 
                (item_code, quantity, requested_date, requested_by, status)
                VALUES (
                    " . $this->db->quote($order['item_code']) . ",
                    " . $order['quantity'] . ",
                    " . $this->db->quote($order['due_date']) . ",
                    " . $this->db->quote($_SESSION['wa_current_user']->username) . ",
                    'pending'
                )";

        $requisitionId = $this->db->executeUpdate($sql);

        if ($requisitionId) {
            $this->markAsConverted($orderId);
        }

        return $requisitionId;
    }

    /**
     * Convert planned order to work order.
     */
    public function convertToWorkOrder(int $orderId): ?int
    {
        $order = $this->getOrderById($orderId);
        if (!$order || $order['order_type'] !== self::TYPE_WORK_ORDER) {
            return null;
        }

        $sql = "INSERT INTO 0_workorders 
                (stock_id, quantity, required_date, type, status)
                VALUES (
                    " . $this->db->quote($order['item_code']) . ",
                    " . $order['quantity'] . ",
                    " . $this->db->quote($order['due_date']) . ",
                    1,
                    1
                )";

        $workOrderId = $this->db->executeUpdate($sql);

        if ($workOrderId) {
            $this->markAsConverted($orderId);
        }

        return $workOrderId;
    }

    private function getOrderById(int $orderId): ?array
    {
        $sql = "SELECT * FROM 0_mrp_planned_orders WHERE order_id = " . (int)$orderId;
        $result = $this->db->fetchAssoc($sql);
        return $result ?: null;
    }

    private function markAsConverted(int $orderId): bool
    {
        $sql = "UPDATE 0_mrp_planned_orders 
                SET status = " . $this->db->quote(self::STATUS_CONVERTED) . "
                WHERE order_id = " . (int)$orderId;

        return $this->db->executeUpdate($sql) !== false;
    }
}
```

### 5.2 Database Schema

```sql
CREATE TABLE IF NOT EXISTS `0_mrp_planned_orders` (
    `order_id` INT(11) NOT NULL AUTO_INCREMENT,
    `item_code` VARCHAR(20) NOT NULL,
    `order_type` VARCHAR(10) NOT NULL COMMENT 'PO=Purchase, WO=Work Order',
    `quantity` DECIMAL(15,3) NOT NULL,
    `due_date` DATE NOT NULL,
    `start_date` DATE NOT NULL,
    `source_demand_id` INT(11) DEFAULT NULL,
    `status` VARCHAR(20) DEFAULT 'PLANNED',
    `firm` TINYINT(1) DEFAULT 0,
    `lot_sizing_method` VARCHAR(10) DEFAULT 'LFL',
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`order_id`),
    KEY `idx_item_code` (`item_code`),
    KEY `idx_due_date` (`due_date`),
    KEY `idx_status` (`status`),
    KEY `idx_firm` (`firm`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
