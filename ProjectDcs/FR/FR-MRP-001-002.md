# FR-MRP-001-002 - Demand Aggregation

**Business Requirement**: BR-MRP-001
**Functional Requirement ID**: FR-MRP-001-002
**Status**: Proposed
**Module**: ksf_FA_MRP
**PHP Version**: 7.3+

---

## 1. Requirement

The MRP system shall aggregate all sources of demand into a unified demand list for planning purposes.

## 2. Description

Demand aggregation collects independent demand from multiple sources (sales orders, forecasts, safety stock requirements, work orders) and combines them by item code and due date into time-phased gross requirements.

## 5. Technical Implementation

### 5.1 Demand Aggregation Service

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\MRP;

/**
 * Demand Aggregation Service.
 * Aggregates demand from multiple sources.
 *
 * @BABOK Related: FR-MRP-001-002
 */
class DemandAggregationService
{
    private $db;
    private $parameters;

    public function __construct(DbConnectionInterface $db, MRPParametersService $parameters)
    {
        $this->db = $db;
        $this->parameters = $parameters;
    }

    public function aggregateDemands(): array
    {
        $horizonDays = $this->parameters->getPlanningHorizon();
        $cutoffDate = date('Y-m-d', strtotime("+{$horizonDays} days"));

        $demands = [];
        $demands = array_merge($demands, $this->collectSalesOrders($cutoffDate));
        $demands = array_merge($demands, $this->collectForecasts($cutoffDate));
        $demands = array_merge($demands, $this->collectWorkOrders($cutoffDate));
        $demands = array_merge($demands, $this->collectSafetyStock());

        return $this->groupByItemAndDate($demands);
    }

    private function collectSalesOrders(string $cutoffDate): array
    {
        $sql = "SELECT 
                    sod.stock_id AS item_code,
                    sod.delivery_date AS due_date,
                    SUM(sod.quantity) AS quantity,
                    sod.order_no AS source_id,
                    5 AS priority
                FROM 0_sales_order_details sod
                JOIN 0_sales_orders so ON sod.order_no = so.order_no
                WHERE sod.delivery_date <= " . $this->db->quote($cutoffDate) . "
                  AND sod.quantity > sod.qty_sent
                  AND so.status = 1
                GROUP BY sod.stock_id, sod.delivery_date, sod.order_no";

        $results = $this->db->fetchAll($sql);
        return $this->tagDemandType($results, 'SO');
    }

    private function collectForecasts(string $cutoffDate): array
    {
        $sql = "SELECT 
                    forecast_item AS item_code,
                    forecast_date AS due_date,
                    SUM(forecast_qty) AS quantity,
                    NULL AS source_id,
                    3 AS priority
                FROM 0_forecast
                WHERE forecast_date <= " . $this->db->quote($cutoffDate) . "
                  AND forecast_qty > 0
                GROUP BY forecast_item, forecast_date";

        $results = $this->db->fetchAll($sql);
        return $this->tagDemandType($results, 'FC');
    }

    private function collectWorkOrders(string $cutoffDate): array
    {
        $sql = "SELECT 
                    wo.stock_id AS item_code,
                    wo.required_date AS due_date,
                    wo.quantity AS quantity,
                    wo.id AS source_id,
                    7 AS priority
                FROM 0_workorders wo
                WHERE wo.required_date <= " . $this->db->quote($cutoffDate) . "
                  AND wo.status IN (1, 2)
                ORDER BY wo.required_date";

        $results = $this->db->fetchAll($sql);
        return $this->tagDemandType($results, 'WO');
    }

    private function collectSafetyStock(): array
    {
        $sql = "SELECT 
                    stock_id AS item_code,
                    CURDATE() AS due_date,
                    safety_stock AS quantity,
                    NULL AS source_id,
                    9 AS priority
                FROM 0_stock_master
                WHERE safety_stock > 0";

        $results = $this->db->fetchAll($sql);
        return $this->tagDemandType($results, 'SS');
    }

    private function tagDemandType(array $demands, string $type): array
    {
        return array_map(function ($demand) use ($type) {
            $demand['demand_type'] = $type;
            return $demand;
        }, $demands);
    }

    private function groupByItemAndDate(array $demands): array
    {
        $grouped = [];

        foreach ($demands as $demand) {
            $key = $demand['item_code'] . '|' . $demand['due_date'];
            if (!isset($grouped[$key])) {
                $grouped[$key] = $demand;
            } else {
                $grouped[$key]['quantity'] += $demand['quantity'];
                $grouped[$key]['priority'] = max($grouped[$key]['priority'], $demand['priority']);
            }
        }

        return array_values($grouped);
    }

    public function saveDemands(array $demands): bool
    {
        $this->db->executeUpdate("DELETE FROM 0_mrp_demands");

        foreach ($demands as $demand) {
            $sql = "INSERT INTO 0_mrp_demands 
                    (item_code, demand_type, source_id, quantity, due_date, priority)
                    VALUES (
                        " . $this->db->quote($demand['item_code']) . ",
                        " . $this->db->quote($demand['demand_type']) . ",
                        " . $this->db->quote($demand['source_id']) . ",
                        " . $demand['quantity'] . ",
                        " . $this->db->quote($demand['due_date']) . ",
                        " . $demand['priority'] . "
                    )";
            $this->db->executeUpdate($sql);
        }

        return true;
    }
}
```

### 5.2 Database Schema

```sql
CREATE TABLE IF NOT EXISTS `0_mrp_demands` (
    `demand_id` INT(11) NOT NULL AUTO_INCREMENT,
    `item_code` VARCHAR(20) NOT NULL,
    `demand_type` VARCHAR(20) NOT NULL COMMENT 'SO=Sales Order, WO=Work Order, FC=Forecast, SS=Safety Stock',
    `source_id` VARCHAR(20) DEFAULT NULL,
    `quantity` DECIMAL(15,3) NOT NULL,
    `due_date` DATE NOT NULL,
    `priority` INT(11) DEFAULT 1,
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`demand_id`),
    KEY `idx_item_code` (`item_code`),
    KEY `idx_due_date` (`due_date`),
    KEY `idx_demand_type` (`demand_type`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
